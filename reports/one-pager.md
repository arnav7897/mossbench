# Trying Moss Inference

I built a documentation assistant on Moss to see what happens between finding a source, answering a question and checking the answer in a browser. [Code, scripts and measured results](https://github.com/arnav7897/mossbench)

**Portal.** I liked being able to follow a Playground answer straight into Logs & Traces and see which model ran, how many tokens it used and whether it searched an index. Keyboard search took me to Models with Enter. Two things slowed me down. Models marked Fastlane as the default while Playground used DeepSeek, and the index picker stayed open after Escape and blocked clicks until I reloaded. I’d show the active model and indexes beside the prompt and make Escape return focus to the picker button.

**Inference API.** I compared three answer paths on 40 questions from 18 official documentation pages. Direct answers got 31 right, adding the top three passages myself got 30, and Moss-hosted retrieval got 32. The hybrid search found the right page in the top ten on all 40 questions. Yet both retrieval paths told me Celery’s task rate limits apply globally. They apply per worker. I’d expose the passage behind each hosted answer so a developer can tell whether the search missed the relevant paragraph or the model misread it. In a separate 150-call comparison under a 64-token output cap, Fastlane completed 75/75 multiple-choice answers correctly. DeepSeek Flash completed 47/75 correctly and marked 28 incomplete.

**Tasks API.** I tested extraction, an unreachable page, cancellation, resuming with a fresh client, duplicate submissions and downloading an artifact. All four structured extraction outputs passed validation. Reusing an idempotency key returned the same task ID, which makes recovery easier after a dropped connection. When I asked whether a page was reachable, the task correctly reported it was unreachable. I’d change how the spend limit is presented. One task stopped with `budget_exceeded` after reporting $0.017258 in model usage against its $0.01 limit. Moss documents that calls in flight can still bill. I’d explain this beside the limit and offer a strict cap for developers who need one.
